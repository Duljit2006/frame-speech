The Encoder-Decoder Cross-Attention Failure

Why standard monolithic transcription engines hallucinate on out-of-distribution code-switched phonemes.

Pure Whisper ASR

Models like Whisper rely on global language tokens. When a speaker switches languages mid-sentence, the attention heads collapse, causing the decoder to hallucinate or forcefully transliterate out-of-vocabulary words into the dominant script.

// Audio input: "In Hindi we say समय, too different!"

❌ Decoder output:
"In Hindi we say samay, too different!" (Loss of native script)
- OR -
"इन हिंदी वी से समय टू डिफरेंट" (Loss of Latin code-switch)

FrameSpeech Pipeline

We bypass global token reliance by isolating language domains via 0.5s temporal binning. We force targeted language hints per tensor slice, then reconstruct the semantic structure using LLM orthographic post-processing.

// Audio input: "In Hindi we say समय, too different!"

✅ FrameSpeech output:
"In Hindi we say समय, too different!"
(Perfect word-level bilingual boundary preservation)

7-Stage Tensor Pipeline

Detailed breakdown of audio processing algorithms and model parameters.

Stage 01

Audio Extractor

Uses yt-dlp and ffmpeg-python. Resamples input streams to 16kHz, downmixes to mono (ac=1), and forces PCM 16-bit little-endian (pcm_s16le) encoding to normalize mel-spectrogram generation.

Sample Rate: 16000Hz | Channels: 1
Stage 02

Silero VAD

Evaluates float32 audio tensors via a lightweight PyTorch neural VAD. Identifies active speech indices against a strict probability threshold to strip compute-heavy silence.

Confidence Threshold: ≥ 0.50
Stage 03

Segmentation

Generates sequential overlapping audio frames using a targeted sliding window algorithm to ensure boundary phonetic transitions are fully captured for the classifier.

Window: 3.0s | Stride: 1.0s | Overlap: 66%
Stage 04

SpeechBrain LID

Executes vectorized inference on 107-class ECAPA-TDNN embeddings. Applies an -inf log-softmax mask to filter out non-Indian language classes prior to activation.

Batch Size: 32 | Fallback Threshold: < 0.70
Stage 05

Timeline Smoother

Consolidates raw predictions via non-linear median filtering and confidence-weighted majority voting across 0.5s bins. Applies multi-pass glitch absorption for blocks under 2.5s.

Time Bin Resolution: 0.5s
Stage 06

faster-whisper

Executes CTranslate2 int8 quantized transcription. Disables internal redundant VAD. Applies gated language hinting and drops segments where alpha_count < length * 0.3.

Hint Gate: ≥ 0.85 | Quantization: int8
Stage 07

Gemini AI Corrector

Restructures textual fragments into complete sentences while enforcing zero-shot code-switching rules. Utilizes strict JSON schema parsing and dynamic exponential backoff on 429 errors.

Batch Size: 100 | Temp: 0.2 | format: JSON

GPU VRAM Choreography (orchestrator.py)

Memory Management 
# Problem: RTX 2050 (4GB) cannot hold SpeechBrain (LID) and Whisper large-v3 simultaneously.
# Solution: CTranslate2 objects cannot use .to("cpu"). We must explicitly destroy and clear CUDA cache.

# 1. Offload LID models from GPU
self.lid.sb_model.to("cpu")
if self.lid.whisper_model:
    del self.lid.whisper_model  # Destroy fallback Whisper instance
    self.lid.whisper_model = None
torch.cuda.empty_cache()  # Free VRAM for Transcriber

# 2. Load Transcriber (heavy int8 CTranslate2 model)
transcriber = TranscriptionProcessor(model_size=model_size, device=self.device)
transcription_segments = transcriber.transcribe(...)

# 3. Destroy Transcriber & Reload LID
del transcriber
torch.cuda.empty_cache()
self.lid.sb_model.to(self.device) # Return to ready state

Key Technical Innovations

Novel engineering solutions developed to solve complex multimodal hardware bottlenecks.

The Assamese Script Hack

Whisper lacks native Assamese acoustic models and outputs Romanized gibberish. We route Assamese speech through Whisper's strong Bengali Eastern Nagari model, then use LLM targeted substitution in Stage 7 to restore authentic Assamese orthography (র → ৰ, ব → ৱ).

Zero-Risk GFLOPs Optimization

Reduced total inference time by 30% by batching LID chunks into [32, time] GPU forward passes, eliminating redundant Whisper vad_filter=True computations, and merging same-language adjacent temporal blocks prior to decoder execution.

Full-Context Two-Pass Gemini Batching

To avoid output token cutoffs while preserving narrative continuity across a 15-minute file, the concatenated transcript is passed as a read-only semantic context block, while segments are processed in vectorized batches of 100 with dynamic retryDelay exponential backoff parsing.
